# RoomNexa 🏨

**Cloud-based Hotel Property Management System (PMS) for independent hotels.**

We help small and independent hotels take bookings online, run the front desk, stay GST-compliant, and sell rooms across OTAs — without enterprise complexity.

## What we build

- ☁️ **Cloud PMS** — reservations, front desk, housekeeping, night audit
- 🧾 **GST-ready billing** — CGST/SGST/IGST breakup, SAC codes, GSTR-ready reports for Indian hotels
- 🔗 **Channel manager** — sync rates & availability across MakeMyTrip, Goibibo, Booking.com, Expedia, Airbnb
- 🖥️ **Booking engine** — take direct, commission-free bookings on your own website
- 🆓 **Free plan** — start at ₹0, upgrade when you grow
